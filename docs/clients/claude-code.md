# Claude Code

Claude Code uses NASA Chat's Anthropic-compatible gateway. It is not a generic client for OpenAI-compatible APIs, so Mission AI LiteLLM is not configured here.

## Install

Use the current [Claude Code setup documentation](https://code.claude.com/docs/en/setup). Confirm the installation with:

```bash
claude --version
claude doctor
```

## Configure an approved gateway

1. Copy the `env` and `model` settings from the [Claude Code template](../../templates/claude-code/settings.json.example) into `~/.claude/settings.json`, merging rather than replacing existing settings.
2. In the terminal session where you will launch Claude Code, provide your NASA Chat key without adding it to `settings.json`:

   ```bash
   export ANTHROPIC_API_KEY="your-nasa-chat-key"
   claude
   ```

3. Run `claude doctor`, then `/status`, to verify the configured base URL and environment-provided API key.

## Notes

`ANTHROPIC_BASE_URL` is `https://api.asksage.ai.nasa.gov/server/anthropic`, with no trailing `/v1`. Claude Code appends `/v1/messages`; including `/v1` here causes the invalid `/v1/v1/messages` path and can appear as a misleading model error.

The configuration disables adaptive thinking and experimental beta request fields because some gateway versions reject them. If the initial API-key approval was declined, Claude Code can return to the login selector and ignore the configured key. Follow the troubleshooting guidance in the source documentation before changing `~/.claude.json`.

The service owner, not this repository, determines allowed models, permissions, logging, data handling, certificates, and network controls. Review the [Claude Code gateway documentation](https://code.claude.com/docs/en/llm-gateway) for traffic that can still be generated by specific features.
