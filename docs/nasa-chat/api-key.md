# Get a NASA Chat API Key

Use this guide only if you are authorized to use NASA Chat.

## Request access

1. Submit a NAMS request for NASA Chat access.
2. Wait for the request to be approved before attempting to create an API key.

## Create an API key

1. Open [NASA Chat](https://chat.asksage.ai.nasa.gov/).
2. Sign in through Launchpad using your PIV card.
3. In the lower-left corner, select your name, then select **Settings**.
4. In the Settings dialog, select **API Keys**.
5. Enter a descriptive API-key name, then select **Create Key**.
6. Copy the newly created key and enter it directly into the authorized client or local credential mechanism.

Treat the key as a password. Do not commit it, share it in chat or email, add it to a GitHub issue or pull request, or place it in a shared configuration file. Create a separate, descriptively named key for each client or device when practical, and revoke keys you no longer use.
